What does this permission actually allow?

Type a Linux mode as numbers (750) or letters (rwxr-x---). You’ll see what the owner, the group and everyone else can do, and any security red flags.

New to Linux permissions? Read this first

  1. Three kinds of people

    Every file has an owner (usually whoever created it), a group (a team of users), and everyone else.

  2. Three switches each

    r
    read: open and look at it
    w
    write: change it
    x
    run it as a program (on a folder: go inside)
    -
    that switch is off

  3. Numbers are a shortcut

    r = 4, w = 2, x = 1. Add up the switches that are on: 7 = 4+2+1 = rwx, 5 = 4+1 = r-x, 0 = nothing. So 750 means owner 7, group 5, everyone else 0.
